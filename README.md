# 🔐 Login Page

A simple and responsive login page built to practice and demonstrate modern web development skills.

## ✨ Features

* 🔑 Username/Email and Password fields
* 📱 Responsive design
* 🎨 Clean and user-friendly UI
* 🔗 Forgot password option
* 📝 Sign-up/Register option

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/anishsharma90/Website-login-page.git
```

### 2. Open the project

Go to the project folder:

```bash
cd Website-login-page
```

### 3. Run the project

Open `index.html` in your browser.
